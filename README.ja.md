## 三、なぜ一律に「概念 DOI」を引くのか

Zenodo の各記録には二つの番号がある：

| 番号 | 性質 | 挙動 |
|:---|:---|:---|
| **概念 DOI（concept DOI）** | 合集級 | **その合集の最新版を永久に指す** |
| 版本 DOI（version DOI） | 記録級 | ある版に固定され、新版が出ても**ついてこない** |

ゆえに本索引は一律に**概念 DOI**のみを公布する。後にデータセットが新版を出しても、同じ番号がそのまま使え、旧版に止まることはない。

## 四、使用の境界

- 両データセットが収めるのは**暦法の事実**（時刻・年表・対照表）と**術語の対応関係**のみで、いかなる推断・断語・吉凶宜忌・個体への指向も含まない。
- 術語表第十九組「術数択日」は**術語名とその界定**のみを収め、いかなる択日の方法や用法の説明も含まない。
- 具体的な節気時刻を引くときは、**中国科学院紫金山天文台**《中国天文年暦》／《暦日資料》（GB/T 33661-2017《農暦の編算と頒行》に依る）を併記するのがよい。本データセットは独立した第二の出所で、復算と長跨度の照会に用いる。
- 歴代暦法改革年表は**編纂表**で、原資料ではない。具体的な年を引く前に考異表を参照のこと。
- 術語表の英語定訳は**作業定訳**であり、排他を主張しない。
